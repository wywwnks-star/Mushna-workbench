# 🚀 创作工作台 - GitHub Pages 部署指南

按照下面的步骤操作，5分钟就能把你的创作工作台部署到公网，手机电脑都能访问！

---

## 📋 准备工作

在开始之前，请确保你已经：

1. ✅ 注册了GitHub账号（https://github.com）
2. ✅ 注册了坚果云账号（https://www.jianguoyun.com）
3. ✅ 在坚果云生成了WebDAV应用密码（下面会讲）

---

## 第一步：配置坚果云WebDAV

### 1.1 获取应用密码
1. 登录 https://www.jianguoyun.com
2. 点击右上角你的账户名 → **账户信息**
3. 点击左侧 **安全选项**
4. 拉到页面最底部，找到 **第三方应用管理**
5. 点击 **添加应用**
6. 应用名称输入：`创作工作台`
7. 点击 **生成密码**
8. **立刻复制生成的密码！**（关闭后就看不到了）

> ⚠️ 注意：这个应用密码不是你的坚果云登录密码！

---

## 第二步：创建GitHub仓库

1. 登录GitHub，点击右上角 **+** → **New repository**
2. 填写：
   - **Repository name**（仓库名）：`creator-workbench`（建议用这个名字）
   - **Description**：自媒体创作者工作台（可选）
   - 选择 **Public**（公开，免费）
   - ✅ 勾选 **Add a README file**
3. 点击 **Create repository**

---

## 第三步：上传PWA文件

### 方式A：网页直接上传（最简单，推荐新手）

1. 在刚创建的仓库页面，点击 **Add file** → **Upload files**
2. 打开本PWA所在的文件夹（`creator-pwa/`）
3. **选中里面的所有文件和文件夹**：
   - `.nojekyll`
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `css/` 文件夹
   - `js/` 文件夹
   - `icons/` 文件夹
4. 把它们全部拖到GitHub的上传页面
5. 滚动到页面底部，点击 **Commit changes**

> 💡 提示：如果是Windows，可以按Ctrl+A全选文件后拖入

### 方式B：Git命令行（适合会用Git的用户）

```bash
git clone https://github.com/你的用户名/creator-workbench.git
cd creator-workbench
# 把所有PWA文件复制到这里
git add .
git commit -m "Deploy creator workbench PWA"
git push
```

---

## 第四步：开启GitHub Pages

1. 在仓库页面，点击顶部的 **Settings**（设置）
2. 左侧菜单往下滚，找到 **Pages**（在Code and automation分类下）
3. 在 **Source** 部分：
   - 第一个下拉框选 **Deploy from a branch**
   - Branch部分，第一个下拉框选 **main**（或master）
   - 第二个下拉框选 **/ (root)**
4. 点击 **Save**
5. 等待1-3分钟，页面顶部会出现一个绿色的网址，类似：
   ```
   🎉 Your site is live at https://你的用户名.github.io/creator-workbench/
   ```

**恭喜！** 你的创作工作台已经上线了！🎉

---

## 第五步：配置跨设备同步

### 在电脑上：

1. 打开你的工作台地址：`https://你的用户名.github.io/creator-workbench/`
2. 点击右上角 **⚙️ 设置**
3. 往下滚动找到 **☁️ WebDAV 云同步（坚果云）**
4. 填写：
   - **服务器地址**：保持默认不要改
     ```
     https://dav.jianguoyun.com/dav/creator-workbench/
     ```
   - **账号邮箱**：你注册坚果云用的邮箱
   - **应用专用密码**：第一步中在坚果云生成的那串密码
5. 点击 **🔌 测试连接**
   - 显示「✅ 已连接」→ 成功！
   - 显示「认证失败」→ 检查邮箱和密码是否正确
6. 点击 **💾 保存配置**
7. 现在可以开始使用了，录入一些数据测试一下
8. 使用完点击 **⬆️ 上传到云端** 做第一次备份

### 在手机上：

1. 用手机浏览器（Safari/Chrome）打开**同一个**地址
2. 同样进入设置页面，填写**完全一样的**WebDAV配置
3. 点击 **🔌 测试连接** 确认成功
4. 点击 **💾 保存配置**
5. 点击 **⬇️ 从云端恢复**
6. 你在电脑上的数据就全部同步到手机了！

---

## 第六步：安装到手机主屏幕（像App一样使用）

### iPhone（Safari）：
1. 打开工作台地址
2. 点击底部的 **分享按钮**（方框带箭头的图标）
3. 往下滑，点击 **添加到主屏幕**
4. 点击右上角 **添加**
5. 主屏幕上就有工作台图标了！

### Android（Chrome）：
1. 打开工作台地址
2. 点击右上角三个点菜单
3. 点击 **添加到主屏幕** / **安装应用**
4. 确认添加

## ❓ 常见问题

**Q: 打开GitHub Pages地址显示404？**
A: 等2-5分钟，GitHub Pages部署需要一点时间。如果还是404，检查Settings → Pages中Branch是否选对了。

**Q: 手机和电脑数据不一样怎么办？**
A: 两边都点一下「🔄 一键同步」。同步策略是：哪边数据新就用哪边的数据覆盖。如果不确定，可以先在数据多的那边点「⬆️上传到云端」，再在另一边点「⬇️从云端恢复」。

**Q: 坚果云免费版够用吗？**
A: 完全够用！创作工作台的数据都是纯文字，1MB就能存几千条记录。坚果云免费版每月1GB上传流量，用不完的。

**Q: 数据安全吗？**
A: 非常安全。数据只存在你的浏览器IndexedDB和你自己的坚果云里，不经过任何第三方服务器。GitHub Pages只托管网页代码，看不到你的数据。

**Q: 更新了代码怎么重新部署？**
A: 重新把新文件上传到GitHub仓库，覆盖旧文件即可，GitHub Pages会自动更新。

**Q: 可以用自己的域名吗？**
A: 可以！在Settings → Pages → Custom domain中设置你的域名即可。

## 🆘 需要帮助？

如果遇到问题，可以检查：
1. 浏览器控制台（F12）有没有红色错误
2. 坚果云应用密码是否正确（不是登录密码！）
3. GitHub Pages是否已经部署完成（等几分钟）
4. 文件是否都上传了，特别是`.nojekyll`文件不要漏了
